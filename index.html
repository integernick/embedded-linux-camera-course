Embedded Linux Camera Course

Camera work on embedded Linux, on a Jetson and a Raspberry Pi 5

Jetson Orin Nano · JetPack 7.2.1Raspberry Pi 5 · Linux 6.18

  • A course on camera work on embedded Linux: sensor driver, device tree, V4L2, the CSI-2 receiver, ISP and auto-exposure, GStreamer, and encoding.
  • It starts at the first out-of-tree kernel module. It needs only hardware that anyone can buy: an Orin Nano developer kit, a Raspberry Pi 5, and Raspberry Pi cameras (IMX477 HQ, IMX219 v2).
  • The Jetson is the default board, on JetPack 7.2.1 (Jetson Linux r39.2.1). A lesson in the new structure shows the Raspberry Pi 5 beside it.
  • The comparison is the method of the course. The same camera needs a different driver, a different device tree and a different pipeline on each board.
  • The repository holds a Jetson sensor driver without hardware access (virtcam) and a userspace configurator (picam-conf). The lessons explain where the layer boundaries are, and how to debug each layer.

Lessons

The course has 23 lessons in six parts. A lesson joins this site when it is written in the two-board form. Each one has a lecture, a lab and a solution. The glossary defines the terms that the lessons use.
